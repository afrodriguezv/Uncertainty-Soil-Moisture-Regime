# Uncertainty in Soil Moisture Regime

Repository containing data, scripts, and analytical workflows developed for the doctoral research:

**“Uncertainty in the Determination and Spatialization of Soil Moisture Regime:  
A Case Study in the Flat Altillanura Region, Meta, Colombia.”**

[![DOI](https://zenodo.org/badge/1201401663.svg)](https://doi.org/10.5281/zenodo.19422691)

---

## 📌 Description

This repository provides the datasets, R scripts, and methodological workflows used to evaluate uncertainty in soil moisture regime (SMR) determination under tropical conditions. The study integrates:

- Field soil moisture observations  
- Soil profile characterization  
- Climate datasets (e.g., CHIRPS, ERA5)  
- Hydrological modeling (Newhall model)  
- Statistical validation (Kappa, contingency analysis)

- Spatial analysis and climate change scenarios (SSP5–RCP8.5)
